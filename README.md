# H3C 维保查询工作台

批量查询华三官网（es.h3c.com/entitlement）设备的维保/保修到期日，自动识别滑块验证码，全程无需人工干预。

> 适用场景：手头有一批 H3C 设备序列号（SN），想快速查出各自的官方维保到期时间，用于过保预警、替换规划。

本工具提供**两种用法**：图形化操作平台（推荐）与原来的命令行脚本（保留，行为不变）。两者共用同一套查询引擎，结果格式一致。

### 启动

- **Windows**：双击 `start-gui.bat`，会自动启动本地服务并打开浏览器。
- **通用方式**：在工具目录执行 `node server.js`，然后访问终端打印的地址（默认 `http://127.0.0.1:8787`）。
- 不想自动打开浏览器：执行 `node server.js --no-browser`。
- 端口被占用时会自动顺延（8788、8789…），以终端打印的地址为准。
- 关闭终端窗口 / 按 `Ctrl+C` 即停止服务。服务**只监听 127.0.0.1**，仅本机可访问。

> 环境要求仍然只有 Node.js ≥ 12，**无需 `npm install`**，零第三方依赖。

### 三步完成一次查询

1. **填序列号**：在输入框粘贴一列 SN，或直接把 `.txt` / `.csv` 文件拖进输入框；也可点「选择文件」「载入示例 SN」。支持逗号 / 空格 / 中文逗号混排，自动去重、忽略空行与非法字符，输入框下方实时显示解析统计。
2. **点「开始查询」**：设置区可调整查询间隔（默认 350ms）、过保预警阈值（默认 90 天）、单台重试次数、验证码上限，以及「遇限频自动重解验证码」开关。快捷键 `Ctrl+Enter` 也能启动。
3. **看结果 / 导出**：实时进度条、当前 SN、逐条日志、成功失败统计同步更新；结果表格按到期紧急程度着色，可搜索、筛选、排序、点击复制 SN；完成后点「导出 CSV」或「导出预警报表」。

### 演示与历史

- 想先看看界面长什么样、或当前网络不通：点「演示结果」，会离线载入示例数据，不发任何真实请求。
- 每完成 / 停止一次任务，结果都会写入 `results/<时间戳>.json` 和 `.csv`；「历史记录」按时间倒序列出最近 30 条，点击即可载回表格。

## 三、输出字段说明

| 列名 | 含义 |
|---|---|
| 序列号 | 设备 SN |
| 保修到期日 | 华三官方维保/保修到期时间（格式 `YYYY-MM-DD HH:MM:SS`） |
| 备注 | 查询状态；失败的会写明原因（如「未找到」「接口异常」「网络错误」等） |

- **保修到期日**取接口返回的 `newEndDate`（identification=Warranty），即华三官方维保到期时间。
- 该接口只返回合并后的维保到期日，**没有单独的「购买日期」「服务到期日」字段**。如需这两列，请用采购合同 / 订购记录另行补充。
- 图形界面的「剩余天数」「预警状态」是本地按当前日期和预警阈值计算出来的衍生字段，不在官网返回值中。
- 个别序列号失败（设备未注册、SN 有误、临时网络异常）不会中断整体任务，该行会写入结果并在备注标注原因。

## 四、常见问题（FAQ）

**Q1：双击 bat 闪一下就没了 / 提示 `node 不是内部或外部命令`？**
A：Node.js 没装或没加入 PATH。到 https://nodejs.org 装 LTS 版（勾选 Add to PATH），重启命令行后再试；也可直接在目录里手动执行 `node server.js` 看报错。

**Q2：浏览器没自动打开？**
A：手动访问终端里打印的地址，一般是 `http://127.0.0.1:8787`。注意服务只监听本机，不能从局域网其他机器访问。

**Q3：运行很慢 / 频繁在解验证码？**
A：华三官网对匿名批量查询有限频（约每 18 次弹一次滑块验证码）。工具会**自动重解**并继续，无需干预，只是多花几秒。设备多时可在设置里把查询间隔调到 500–800ms，降低触发频率。

**Q4：结果为空或大量失败？**
A：先确认 SN 是否正确（华三 SN 一般为 20 位字母数字）；其次可能是官网接口波动或网络问题，重试一次即可。界面「实时日志」会写明每台的具体原因。

**Q5：导入 CSV 后把日期也当成序列号了？**
A：不会。图形界面导入 `.csv` 时只取每行第一列，并自动跳过表头、日期等非 SN 内容。

**Q6：脚本会泄露我的数据吗？**
A：只直接请求华三官方接口（es.h3c.com），序列号仅用于该次查询，不上传任何第三方。图形界面服务只监听 127.0.0.1，不对外暴露。查询频率请遵守目标网站的使用规范。

**Q7：换了台电脑能用吗？**
A：可以。只要目标机器装了 Node.js（≥12），把整个文件夹拷过去即可，零依赖、无需联网安装任何包（查询结果本身需要联网访问华三官网）。

## 五、技术说明

- 查询接口：`GET https://es.h3c.com/entitlement/query/sdms/{序列号}?captchaVerification={令牌}`
- 验证码：aj-captcha 滑块（blockPuzzle），自动完成：
  1. 拉取验证码图片与密钥（`/captcha/get`）
  2. 纯 Node 解码 PNG，用边缘梯度匹配定位滑块缺口 X 坐标
  3. 用服务端下发的 `secretKey` 做 AES-ECB 加密生成验证令牌
  4. 提交校验（`/captcha/check`）
- 图形界面：Node 内置 `http` 起本地服务，浏览器通过 SSE（Server-Sent Events）接收实时进度；前端为原生 HTML/CSS/JS，无框架、无 CDN、无构建步骤。
- 全部使用 Node 内置模块（`https` / `zlib` / `crypto` / `fs` / `http`），无外部依赖。
- 验证码临时图片写到系统临时目录（`os.tmpdir()/h3c-warranty-gui`），不再污染项目目录。项目里残存的 `_cap_orig.png` / `_cap_jig.png` 是旧版脚本留下的，可自行删除。

> 注意：若华三未来改版官网 / 接口结构、或更换验证码类型，识别逻辑可能需要微调。
